# PLS + SCAM 系列结构与审计说明

## 受控修改

四个 YAML 分别以 R03、R04、R10 和 R06 为结构参照。与各自 DPLS 版本相比，只有 Head 中第1、4项发生变化：

```text
DySample ×2  →  nn.Upsample(nearest, scale_factor=2) ×2
```

Backbone、两个 Top-down Concat、两个 Bottom-up PAN Concat、后续 C3k2、三个 SCAM/CA-SCAM 位置和 Detect 输入保持不变。VGUP 与 ERUP 版本只在输入端保留各自已登记的预处理模块。

## 层位置

无输入预处理器的两个实验：

- PLS 上采样：第9、12层；
- PAN Concat：第16、19层；
- SCAM/CA-SCAM：第21、22、23层，分别读取第14、17、20层；
- Detect：第24层，读取 `[21, 22, 23]`。

VGUP/ERUP 实验整体后移一层：

- 输入预处理器：第0层；
- PLS 上采样：第10、13层；
- PAN Concat：第17、20层；
- CA-SCAM：第22、23、24层，分别读取第15、18、21层；
- Detect：第25层，读取 `[22, 23, 24]`。

## 本地审计结果（单类别，imgsz=640）

| 模型 | 参数量 | GFLOPs | Loaded/Total |
|---|---:|---:|---:|
| R01 PLS | 1,259,667 | 14.3314944 | — |
| PLS + CA-SCAM | 1,334,406 | 14.8716512 | 232/505 |
| PLS + SCAM | 1,334,373 | 14.8657216 | 232/496 |
| PLS + CA-SCAM + VGUP | 1,411,802 | 18.3012320 | 232/553 |
| PLS + CA-SCAM + ERUP | 8,115,448 | 77.1202016 | 232/517 |

四个模型均通过以下检查：

- 只存在两个 nearest×2 上采样，不存在 DySample；
- 3个注意力模块的类型、来源层和 Detect 连接正确；
- PAN 路径未改变；
- 检测步长为 `[4, 8, 16]`；
- CPU 前向、反向、输入梯度和参数梯度均为有限值；
- 官方 `yolo11n.pt` 已加载张量在训练器接管前可进行逐张量核验。

ERUP 的参数量和计算量远高于另外三组，因此它是准确性/复杂度权衡实验，不应在论文中描述为轻量模块。

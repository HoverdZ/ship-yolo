# DPLS尺度动机建议文本

在保持长宽比的640×640输入映射下，训练集船舶水平标注框短边的第2.5、第5和第10百分位数分别为11.25、12.50和13.75像素。短边低于4、8、16和32像素的实例比例分别为0.00%、0.46%、17.01%和91.84%。当特征步长不大于所选低分位船舶短边时，目标短边至少覆盖一个特征采样间隔，对应空间稀释率为零；随着步长相对目标短边增大，该指标随之上升，反映特征层对窄小目标的空间表征能力逐渐受限。因此，本文将该统计量用于指导检测金字塔层级选择，并通过D0–D2严格对照实验检验P2–P4层级迁移及DySample的实际检测效果。

> 边界：以上统计提供尺度动机，不直接等价于精度提升证据。
